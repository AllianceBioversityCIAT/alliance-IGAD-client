# Project Guidelines for Claude Code

## Git Workflow Rules

### Commit Creation
- **ONLY** create commits when explicitly told "create commit"
- Do NOT create commits automatically after making changes
- Wait for explicit user instruction before committing

### Push to Remote
- **ONLY** push commits when explicitly told "push"
- Do NOT push automatically after creating a commit
- Wait for explicit user instruction before pushing

## Summary
Always wait for explicit user commands for git operations:
- User says "create commit" → Create the commit
- User says "push" → Push to remote
- Otherwise → Do not perform these actions
